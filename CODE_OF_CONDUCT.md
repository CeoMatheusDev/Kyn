# Code of Conduct

## Our commitment

The Kyn project aims to provide a respectful, constructive and technically rigorous environment for everyone, regardless of experience level, background or identity.

## Expected behavior

- Be respectful and assume good faith.
- Discuss technical decisions using evidence, reproducible behavior and clear reasoning.
- Give actionable feedback; criticize code and ideas, not people.
- Accept responsibility for mistakes and help repair their impact.
- Respect project scope, maintainers' time and other contributors' boundaries.

## Unacceptable behavior

- Harassment, discrimination, threats or personal attacks.
- Deliberate intimidation, doxxing or unwanted disclosure of private information.
- Trolling, sustained disruption or bad-faith participation.
- Publishing credentials, personal data or private communications without permission.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards. They may edit or remove contributions, close discussions, or restrict participation when behavior is harmful or repeatedly disruptive.

Report concerns privately to the repository maintainers through the contact method listed in the GitHub repository profile. Include relevant links or context when safe to do so.

This code of conduct applies in project repositories, issue trackers, pull requests and other spaces officially operated for the Kyn project.
